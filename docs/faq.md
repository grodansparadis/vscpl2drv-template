# FAQ

## What is this driver good for?

By itself: nothing. It is a template that implements all the plumbing a VSCP
level II driver needs, so that you can concentrate on the actual driver
functionality. See [Making a driver from the template](./creating-a-driver.md).

## Where do I find the VSCP level II driver API specification?

[Here](https://grodansparadis.github.io/vscp-doc-spec/#/./vscp_driver_interfaces).
